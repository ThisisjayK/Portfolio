## 2. Definition of done (site)
- [ ] Every fact matches about-me.md
- [ ] Works at phone, tablet and desktop widths with no horizontal scroll
- [ ] Light and dark themes both pass contrast checks
- [ ] Keyboard navigation and visible focus work everywhere
- [ ] Reduced-motion is respected
- [ ] No broken links, and no console errors
- [ ] Performance budget from architecture.md is met
- [ ] Social preview (title, description, image) is set
- [ ] Reviewed by Jayanth before publishing
